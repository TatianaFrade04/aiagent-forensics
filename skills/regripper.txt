## What is RegRipper?
RegRipper is a Perl-based tool that extracts and parses specific forensic artifacts from Windows Registry hive files. It uses plugins to target specific registry keys, making it far more efficient than manual registry browsing.

## Forensic use cases
- List user accounts and last login times (SAM hive)
- Find installed software and versions (SOFTWARE hive)
- Identify USB devices that were connected (SYSTEM hive)
- Discover recently opened files and programs (NTUSER.DAT)
- Extract network connection history
- Identify autorun/startup programs
- Extract shellbags (folder access history)
- Find UserAssist data (program execution counts)

## Registry hive locations on Windows NTFS
- SAM: /WINDOWS/system32/config/SAM
- SYSTEM: /WINDOWS/system32/config/SYSTEM
- SOFTWARE: /WINDOWS/system32/config/SOFTWARE
- SECURITY: /WINDOWS/system32/config/SECURITY
- NTUSER.DAT: /USERS/<username>/NTUSER.DAT
- UsrClass.dat: /USERS/<username>/AppData/Local/Microsoft/Windows/UsrClass.dat

## Key flags
- `-r <hive>`     — Path to the registry hive file
- `-p <plugin>`   — Run a specific plugin
- `-a`            — Run all plugins applicable to the hive type
- `-l`            — List all available plugins

## Usage examples
```bash
# List all available plugins
rip.pl -l

# Run all plugins on the SAM hive (user accounts)
rip.pl -r '/forensics/part006/WINDOWS/system32/config/SAM' -a

# Run all plugins on the SOFTWARE hive (installed programs)
rip.pl -r '/forensics/part006/WINDOWS/system32/config/SOFTWARE' -a

# Run all plugins on NTUSER.DAT (user activity)
rip.pl -r '/forensics/part006/USERS/Jimmy Wilson/NTUSER.DAT' -a

# Run a specific plugin (e.g., userassist for program execution)
rip.pl -r '/forensics/part006/USERS/Jimmy Wilson/NTUSER.DAT' -p userassist

# Run a specific plugin (e.g., recentdocs for recently opened files)
rip.pl -r '/forensics/part006/USERS/Jimmy Wilson/NTUSER.DAT' -p recentdocs

# USB device history from SYSTEM hive
rip.pl -r '/forensics/part006/WINDOWS/system32/config/SYSTEM' -p usbstor

# Save output to exports
rip.pl -r '/forensics/part006/WINDOWS/system32/config/SAM' -a > /exports/sam_report.txt
```

## Tips
- Always use single quotes around hive paths
- Use `-a` for a full audit of a hive, or `-p <plugin>` for targeted extraction
- NTUSER.DAT contains the most user-specific forensic artifacts
- Combine SAM + SYSTEM + SOFTWARE for a complete system profile
