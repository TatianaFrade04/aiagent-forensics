## What is RegRipper?
RegRipper is a Perl-based tool that extracts and parses specific forensic artifacts from Windows Registry hive files. It uses plugins to target specific registry keys, making it far more efficient than manual registry browsing.

## Forensic use cases
- List user accounts and last login times (SAM hive)
- Find installed software and versions (SOFTWARE hive)
- Identify USB devices that were connected (SYSTEM hive)
- Discover recently opened files and programs (NTUSER.DAT)
- Extract network connection history
- Identify autorun/startup programs
- Extract shellbags (folder access history)
- Find UserAssist data (program execution counts)

## Registry hive locations on Windows NTFS
NOTE: Windows directory names are case-sensitive when mounted on Linux (ntfs-3g). The real path may be `Windows/System32` or `WINDOWS/system32` etc. ALWAYS use find -iname to discover the exact path before running regripper.

```bash
SYSTEM_HIVE=$(find /forensics/part006 -iname 'SYSTEM' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1)
regripper -r "$SYSTEM_HIVE" -p usbstor
```

Hive discovery commands:
- `find /forensics/part006 -iname 'SAM'     -not -path '*/Users/*' 2>/dev/null | head -1`
- `find /forensics/part006 -iname 'SYSTEM'  -not -path '*/Users/*' 2>/dev/null | head -1`
- `find /forensics/part006 -iname 'SOFTWARE' -not -path '*/Users/*' 2>/dev/null | head -1`
- `find /forensics/part006 -iname 'NTUSER.DAT' 2>/dev/null`

## Key flags
- `-r <hive>`     — Path to the registry hive file
- `-p <plugin>`   — Run a specific plugin
- `-a`            — Run all plugins applicable to the hive type
- `-l`            — List all available plugins

## Usage examples
```bash
# Step 1: discover hive paths (case-sensitive; exclude non-hive dirs like diagnostics)
SYSTEM_HIVE=$(find /forensics/part006 -iname 'SYSTEM' -not -path '*/Users/*' -not -path '*/diagnostics/*' 2>/dev/null | head -1)
regripper -r "$SYSTEM_HIVE" -p usbstor

SAM_HIVE=$(find /forensics/part006 -iname 'SAM' -not -path '*/Users/*' 2>/dev/null | head -1)
SOFTWARE_HIVE=$(find /forensics/part006 -iname 'SOFTWARE' -not -path '*/Users/*' -not -path '*/diagnostics/*' 2>/dev/null | head -1)
NTUSER=$(find /forensics/part006 -iname 'NTUSER.DAT' 2>/dev/null | grep -i 'Jimmy' | head -1)

# Run all plugins on the SYSTEM hive
regripper -r "$SYSTEM_HIVE" -a

# Run all plugins on the SAM hive (user accounts)
regripper -r "$SAM_HIVE" -a

# Run all plugins on the SOFTWARE hive (installed programs)
regripper -r "$SOFTWARE_HIVE" -a

# Run all plugins on NTUSER.DAT (user activity)
regripper -r "$NTUSER" -a

# Run a specific plugin (e.g., userassist for program execution)
regripper -r "$NTUSER" -p userassist

# List all available plugins
regripper -l

# Save output to exports
regripper -r "$SAM_HIVE" -a > /exports/sam_report.txt
```

## Tips
- Always use single quotes around hive paths
- Use `-a` for a full audit of a hive, or `-p <plugin>` for targeted extraction
- NTUSER.DAT contains the most user-specific forensic artifacts
- Combine SAM + SYSTEM + SOFTWARE for a complete system profile
