## MANDATORY QUERY → COMMAND MAPPING
When the user asks one of these questions, use EXACTLY the command shown — no variations.

| User question (any language)                          | Command to use                                      |
|-------------------------------------------------------|-----------------------------------------------------|
| "when was the OS last used / shutdown / turned off?"  | regripper -r $SYSTEM_HIVE -p shutdown               |
| "when was the OS installed?"                          | reglookup on SOFTWARE + grep InstallDate (see below)|
| "what OS / Windows version is this?"                  | reglookup on SOFTWARE + grep ProductName            |
| "what programs are installed?"                        | reglookup on SOFTWARE /CurrentVersion/Uninstall     |
| "what users exist?"                                   | find '/forensics/part006/USERS' -mindepth 1 -maxdepth 1 -type d |
| "USB devices connected?"                              | regripper -r $SYSTEM_HIVE -p usbstor                |

⚠️ "LAST USED" MEANS SHUTDOWN — NOT SESSION DATA:
The forensic evidence for "when was the system last used" is the last shutdown timestamp in the SYSTEM hive.
DO NOT use PendingFileRenameOperations, LastLogonTimestamp, or any SOFTWARE hive key for this.
The correct command is: regripper -r $SYSTEM_HIVE -p shutdown

## What is RegRipper?
RegRipper is a Perl-based tool that extracts and parses specific forensic artifacts from Windows Registry hive files. It uses plugins to target specific registry keys, making it far more efficient than manual registry browsing.

## Forensic use cases
- List user accounts and last login times (SAM hive)
- Find installed software and versions (SOFTWARE hive)
- Identify USB devices that were connected (SYSTEM hive)
- Discover recently opened files and programs (NTUSER.DAT)
- Extract network connection history
- Identify autorun/startup programs
- Extract shellbags (folder access history)
- Find UserAssist data (program execution counts)

## REGISTRY HIVE MAP — always use the correct hive for the key path

| Key path / artifact                          | Hive file   | Useful plugin        |
|----------------------------------------------|-------------|----------------------|
| CurrentVersion/Run (machine-wide)            | SOFTWARE    | run                  |
| CurrentVersion/Uninstall (installed apps)    | SOFTWARE    | installedprograms    |
| Windows NT/CurrentVersion (OS info)          | SOFTWARE    | winnt_cv             |
| ControlSet001/Enum/USBSTOR (USB devices)     | SYSTEM      | usbstor              |
| ControlSet001/Control/ComputerName           | SYSTEM      | compname             |
| ControlSet001/Services                       | SYSTEM      | services             |
| Last shutdown time                           | SYSTEM      | shutdown             |
| SAM/Domains/Account/Users (accounts)         | SAM         | samparse             |
| Software/.../CurrentVersion/Run (per-user)   | NTUSER.DAT  | run                  |
| Software/.../Explorer/RecentDocs             | NTUSER.DAT  | recentdocs           |
| Software/.../Explorer/UserAssist             | NTUSER.DAT  | userassist           |

NOTE: CurrentVersion/Run exists in BOTH SOFTWARE (machine-wide) AND NTUSER.DAT (per-user).
ALWAYS query both hives when asked about Run/startup keys.

## Registry hive locations on Windows NTFS
NOTE: Windows directory names are case-sensitive when mounted on Linux (ntfs-3g). The real path may be `Windows/System32` or `WINDOWS/system32` etc. ALWAYS use find -iname to discover the exact path before running regripper.

Hive discovery commands (use find -iname to handle case-sensitive Linux paths):
- SAM:        find /forensics/part006 -iname 'SAM' -not -path '*/Users/*' 2>/dev/null | head -1
- SYSTEM:     find /forensics/part006 -iname 'SYSTEM' -not -path '*/Users/*' -not -path '*/RegBack/*' 2>/dev/null | head -1
- SOFTWARE:   find /forensics/part006 -iname 'SOFTWARE' -not -path '*/Users/*' -not -path '*/RegBack/*' 2>/dev/null | head -1
- NTUSER.DAT: find /forensics/part006 -iname 'NTUSER.DAT' 2>/dev/null

⚠️ CRITICAL HIVE CONFUSION WARNING:
/Microsoft/Windows NT/CurrentVersion (OS version, InstallDate) → SOFTWARE hive, NOT SYSTEM.
The `osversion` plugin also runs on SOFTWARE hive. NEVER use SYSTEM hive for OS version queries.

## Key flags
- `-r <hive>`     — Path to the registry hive file
- `-p <plugin>`   — Run a specific plugin
- `-a`            — Run all plugins applicable to the hive type
- `-l`            — List all available plugins

## Usage examples
```bash
# OS version, install date, product name — SOFTWARE hive, reglookup (always works)
# NOTE: InstallDate is returned as a DWORD hex value (Unix timestamp). Convert with:
#   python3 -c "import datetime; print(datetime.datetime.utcfromtimestamp(0x<VALUE>))"
SOFTWARE_HIVE=$(find /forensics/part006 -iname 'SOFTWARE' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1); reglookup -p '/Microsoft/Windows NT/CurrentVersion' "$SOFTWARE_HIVE" | grep -E 'ProductName|InstallDate|RegisteredOwner' | python3 -c "import sys,datetime; [print(l.strip().split('/')[-1].split(',')[0] + ': ' + (datetime.datetime.utcfromtimestamp(int(l.strip().split(',')[2],16)).strftime('%Y-%m-%d %H:%M:%S UTC') if 'InstallDate' in l else l.strip().split(',')[2])) for l in sys.stdin if l.strip()]"

# Installed programs — SOFTWARE hive, correct path /Microsoft/Windows/CurrentVersion/Uninstall
SOFTWARE_HIVE=$(find /forensics/part006 -iname 'SOFTWARE' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1); reglookup -p '/Microsoft/Windows/CurrentVersion/Uninstall' "$SOFTWARE_HIVE" | grep -i DisplayName

# Last system shutdown time — SYSTEM hive with shutdown plugin
# ⚠️ CRITICAL: ALWAYS assign to variable and quote it. NEVER use inline $(...) in -r argument.
# ⚠️ CRITICAL: The -not -path '*/diagnostics/*' filter is MANDATORY — without it, find may
#    return a diagnostics file that is NOT a valid hive, causing 'undefined value' errors.
SYSTEM_HIVE=$(find /forensics/part006 -iname 'SYSTEM' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1); regripper -r "$SYSTEM_HIVE" -p shutdown

# User accounts and last login — SAM hive with samparse plugin (confirmed installed)
SAM_HIVE=$(find /forensics/part006 -iname 'SAM' -not -path '*/Users/*' 2>/dev/null | head -1); regripper -r "$SAM_HIVE" -p samparse

# USB devices connected — SYSTEM hive with usbstor plugin (confirmed installed)
SYSTEM_HIVE=$(find /forensics/part006 -iname 'SYSTEM' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1); regripper -r "$SYSTEM_HIVE" -p usbstor

# Startup/autorun programs — SOFTWARE hive
SOFTWARE_HIVE=$(find /forensics/part006 -iname 'SOFTWARE' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1); reglookup -p '/Microsoft/Windows/CurrentVersion/Run' "$SOFTWARE_HIVE"

# Run all plugins on the SAM hive
SAM_HIVE=$(find /forensics/part006 -iname 'SAM' -not -path '*/Users/*' 2>/dev/null | head -1); regripper -r "$SAM_HIVE" -a

# Run all plugins on the SOFTWARE hive
SOFTWARE_HIVE=$(find /forensics/part006 -iname 'SOFTWARE' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1); regripper -r "$SOFTWARE_HIVE" -a

# List all available plugins (to check what is installed)
regripper -l
```

## Tips
- Always use single quotes around hive paths
- Use `-a` for a full audit of a hive, or `-p <plugin>` for targeted extraction
- NTUSER.DAT contains the most user-specific forensic artifacts
- Combine SAM + SYSTEM + SOFTWARE for a complete system profile
