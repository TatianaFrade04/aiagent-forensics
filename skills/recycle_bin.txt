## What is the Recycle Bin?
Files deleted via Windows Explorer go to `$RECYCLE.BIN\<SID>\`. Each deleted item creates:
- `$I<hash>` — metadata: original full path, original file size, deletion timestamp
- `$R<hash>` — the actual deleted content (file or folder tree)

The SID directory identifies the user who deleted the item.

## CRITICAL: path and tool rules

NEVER search for `$RECYCLE.BIN` with `find` — it is ALWAYS at `{evidence}/$RECYCLE.BIN`. Use the path directly.
NEVER use `strings` or `strings -e l` — they fail silently on Win10+ $I files.
NEVER use `python3 -c "..."` with double quotes — bash expands `$RECYCLE` → path breaks.
ALWAYS use `python3 << 'PYEOF'` heredoc (single-quoted delimiter prevents all expansion).

## STEP 0 — Always list everything first (no keyword filter)

Run this FIRST before any keyword search. It shows all deleted items and SIDs so you know what to look for.

```bash
python3 << 'PYEOF'
import os, struct
base = '{evidence}/$RECYCLE.BIN'
for sid in os.listdir(base):
    sp = os.path.join(base, sid)
    if not os.path.isdir(sp): continue
    for fn in sorted(os.listdir(sp)):
        if not fn.startswith('$I'): continue
        fpath = os.path.join(sp, fn)
        try:
            data = open(fpath, 'rb').read()
            if len(data) < 28: continue
            version = struct.unpack_from('<Q', data, 0)[0]
            if version == 2:
                path_len = struct.unpack_from('<I', data, 24)[0]
                path = data[28:28+path_len*2].decode('utf-16-le', errors='replace')
            else:
                path = data[24:].decode('utf-16-le', errors='replace').split('\x00')[0]
            print(f'SID={sid} [{fn}]: {path}')
        except Exception as e:
            print(f'ERR {fpath}: {e}')
PYEOF
```

If the output is empty: the `$R` entries may be directories (folder deletion). Check with:
```bash
ls -la '{evidence}/$RECYCLE.BIN/'
find '{evidence}/$RECYCLE.BIN' -maxdepth 3 -type d 2>/dev/null
```

$I binary format:
- Version 1 (Vista/7/8): path at offset 24, null-terminated UTF-16LE
- Version 2 (Win10+): path length (chars) at bytes 24-27, path at offset 28, NOT null-terminated

Use `struct` to detect version and extract path correctly:
```bash
python3 << 'PYEOF'
import os, struct
base = '{evidence}/$RECYCLE.BIN'
for sid in os.listdir(base):
    sp = os.path.join(base, sid)
    if not os.path.isdir(sp): continue
    for fn in os.listdir(sp):
        if not fn.startswith('$I'): continue
        fpath = os.path.join(sp, fn)
        try:
            data = open(fpath, 'rb').read()
            if len(data) < 28: continue
            version = struct.unpack_from('<Q', data, 0)[0]
            if version == 2:
                path_len = struct.unpack_from('<I', data, 24)[0]
                path = data[28:28 + path_len*2].decode('utf-16-le', errors='replace')
            else:
                path = data[24:].decode('utf-16-le', errors='replace').split('\x00')[0]
            if ':' in path:
                print('SID=' + sid + ': ' + path)
        except Exception as e:
            print('ERR ' + fpath + ': ' + str(e))
PYEOF
```

## CRITICAL: getting the original file size
NEVER run `stat` on a `$I` file — it always returns ~544 bytes (the metadata file size, not the original).
```bash
# Option A (simplest): stat the $R file — its size = original logical size
stat -c "%s" '{evidence}/$RECYCLE.BIN/<SID>/$R<hash>'

# Option B: read size from $I binary (bytes 8-15, little-endian uint64)
python3 << 'PYEOF'
import struct
data = open('{evidence}/$RECYCLE.BIN/<SID>/$I<hash>', 'rb').read()
print('Original size:', struct.unpack_from('<Q', data, 8)[0], 'bytes')
PYEOF
```

## Identifying a specific user's deleted files

**Step 1a — Search $I metadata for directly-deleted files (keyword in $I path):**
```bash
python3 << 'PYEOF'
import os, struct
base = '{evidence}/$RECYCLE.BIN'
keyword = '<filename_fragment>'
for sid in os.listdir(base):
    sp = os.path.join(base, sid)
    if not os.path.isdir(sp): continue
    for fn in os.listdir(sp):
        if not fn.startswith('$I'): continue
        fpath = os.path.join(sp, fn)
        try:
            data = open(fpath, 'rb').read()
            if len(data) < 28: continue
            version = struct.unpack_from('<Q', data, 0)[0]
            if version == 2:
                path_len = struct.unpack_from('<I', data, 24)[0]
                path = data[28:28 + path_len*2].decode('utf-16-le', errors='replace')
            else:
                path = data[24:].decode('utf-16-le', errors='replace').split('\x00')[0]
            if keyword.lower() in path.lower():
                print('SID=' + sid + ': ' + path)
        except Exception as e:
            print('ERR ' + fpath + ': ' + str(e))
PYEOF
# If two filenames, run twice with different keywords.
```

**Step 1b — ALSO search inside $R directories (deleted folders):**

**CRITICAL:** When a **folder** is deleted, the `$I` records only the folder name (e.g. `New Prices`),
NOT the individual files inside it. The files live inside the `$R` directory — Step 1a will miss them.
```bash
find '{evidence}/$RECYCLE.BIN' -mindepth 2 -maxdepth 2 -name '$R*' -type d 2>/dev/null | while read rdir; do
  result=$(find "$rdir" -iname '*<filename_fragment>*' 2>/dev/null)
  [ -n "$result" ] && echo "SID=$(basename $(dirname "$rdir")): $result"
done
# Replace '<filename_fragment>' with the actual filename fragment.
```

**Step 2 — Map SID to username (TWO methods, use both):**

Method A — SOFTWARE ProfileList (most reliable):
```bash
HIVE=$(find '{evidence}' -path '*/System32/config/SOFTWARE' -not -path '*/RegBack/*' 2>/dev/null | head -1)
reglookup "$HIVE" 2>/dev/null | grep -i 'ProfileList' | grep -i 'ProfileImagePath'
# → /Microsoft/.../ProfileList/S-1-5-21-...-XXXX/ProfileImagePath|SZ|C:\Users\<username>
# NOTE: RegisteredOwner is NOT the same as a user's SID — never use it for SID mapping.
```

Method B — Extract RID from SID and match against SAM hive:
```
SID format: S-1-3-21-<subauth1>-<subauth2>-<subauth3>-<RID>
                                                         ^^^
The LAST number after the final dash is the RID in DECIMAL.
Convert to hex: printf '0x%X\n' <RID_decimal>

Example: S-1-7-22-111111111-222222222-333333333-1009
         Last segment = 1009 decimal → printf '0x%X\n' 1009 → 0x3ED
         Compare 0x3ED against reglookup SAM output to find which username has RID 3ED.
         RID 1001 = 0x3E9, RID 1002 = 0x3EA, RID 1003 = 0x3EB, etc. — never assume.

NEVER assume or guess which user owns a SID — always compute the decimal→hex conversion
and compare the result to the RID values returned by the SAM hive query.
```

Both files must appear under the same SID, and that SID must map to the named user.

## Tips
- SID directory under `$RECYCLE.BIN` IS the user identifier — no binary extraction needed
- `$R` entries can be files OR directories (when a folder was deleted)
- Shift+Delete bypasses the Recycle Bin — those files are NOT here, require carving tools
- To list SIDs: `find '{evidence}/$RECYCLE.BIN' -mindepth 1 -maxdepth 1 -type d 2>/dev/null`
- CRITICAL: `printf '0x%X\n' <decimal_rid>` converts decimal to hex for SAM comparison
