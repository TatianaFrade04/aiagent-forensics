## What are Windows Event Logs?
Windows Event Logs (`.evtx`) record system activity: boots, shutdowns, logins, application launches, and errors. The three main logs are `System.evtx`, `Security.evtx`, and `Application.evtx`. Located at `Windows/System32/winevt/Logs/`.

## Key Event IDs
| ID   | Log      | Source                         | Meaning |
|------|----------|--------------------------------|---------|
| 12   | System   | Microsoft-Windows-Kernel-General | **OS started** — use THIS for uptime (sub-second precision) |
| 6005 | System   | EventLog                       | EventLog service started (~15 s after boot — do NOT use for uptime) |
| 6006 | System   | EventLog                       | EventLog service stopped → clean shutdown |
| 6009 | System   | EventLog                       | Windows version logged at boot |
| 6013 | System   | EventLog                       | Uptime at previous shutdown |
| 4624 | Security | Security                       | Successful logon |
| 4634 | Security | Security                       | Logoff |
| 4648 | Security | Security                       | Logon with explicit credentials |

## CRITICAL: use Event ID 12, NOT Event ID 6005, for uptime

Event ID **12** (source: `Microsoft-Windows-Kernel-General`) is written by the kernel the instant
Windows starts. Its `TimeCreated SystemTime` has **sub-second precision** and is the actual OS
start time. Event ID 6005 is the EventLog service starting, which happens ~15 seconds later —
using it will produce an answer that is ~15 seconds too low.

Example:
- Event ID 12:   `YYYY-MM-DD HH:MM:SS.ffffff+00:00`  → subtract from target time = actual uptime ✓
- Event ID 6005: `YYYY-MM-DD HH:MM:SS+00:00`          → ~15 s later than ID 12 = too low ✗

## Step-by-step workflow

```bash
# 1. Find all event log files
find '{evidence}' -iname '*.evtx' -type f 2>/dev/null

# 2. Parse System.evtx using python-evtx (Evtx.Evtx) — the ONLY working library
#    CRITICAL: DO NOT use 'import evtx' (omerbenamram) — it fails with 'Failed to parse chunk header'
#    CRITICAL: DO NOT use 'with evtx.PyEvtxParser(path) as p' — context manager not supported
#    ALWAYS use: import Evtx.Evtx as evtx

# 3. Calculate uptime — use Event ID 12 (Kernel-General), NOT 6005
#    CRITICAL: find the MOST RECENT boot BEFORE the target time (not the overall most recent)
#    Copy-paste this script EXACTLY — replace only YEAR, MONTH, DAY, HOUR, MIN, SEC with integers
EVTX=$(find '{evidence}' -iname 'System.evtx' 2>/dev/null | head -1)
python3 << EOF
from Evtx.Evtx import Evtx
from datetime import datetime, timezone
import xml.etree.ElementTree as ET
evtx_path = '$EVTX'
target_dt = datetime(YEAR, MONTH, DAY, HOUR, MIN, SEC, tzinfo=timezone.utc)
boots = []
ns = {'e': 'http://schemas.microsoft.com/win/2004/08/events/event'}
with Evtx(evtx_path) as log:
    for r in log.records():
        try:
            root = ET.fromstring(r.xml())
            eid = root.find('.//e:EventID', ns)
            if eid is not None and eid.text == '12':
                ts_node = root.find('.//e:TimeCreated', ns)
                if ts_node is not None:
                    boots.append(datetime.fromisoformat(ts_node.get('SystemTime', '')))
        except: pass
print('All Event ID 12 boots:', [str(t) for t in sorted(boots)])
boots_before = [t for t in boots if t < target_dt]
if boots_before:
    last_boot = max(boots_before)
    print('Last boot before target:', last_boot)
    print('Uptime (s):', int((target_dt - last_boot).total_seconds()))
else:
    print('No boot found before target. All boots:', [str(t) for t in sorted(boots)])
EOF

# 4. Shutdown events (Event ID 6006)
python3 -c "
import Evtx.Evtx as evtx, re
path = '{evidence}/Windows/System32/winevt/Logs/System.evtx'
last_shutdown = None
with evtx.Evtx(path) as log:
    for r in log.records():
        xml = r.xml()
        if '>6006<' in xml:
            m = re.search(r'SystemTime=\"([^\"]+)\"', xml)
            if m: last_shutdown = m.group(1)
print('Last shutdown:', last_shutdown)
"

# 5. Application last-run events — check Application log
python3 -c "
import Evtx.Evtx as evtx, re
path = '{evidence}/Windows/System32/winevt/Logs/Application.evtx'
with evtx.Evtx(path) as log:
    for r in log.records():
        xml = r.xml()
        m_id = re.search(r'>(\d+)<\/EventID', xml)
        m_ts = re.search(r'SystemTime=\"([^\"]+)\"', xml)
        if m_id and m_ts: print(f'ID={m_id.group(1):6s}  {m_ts.group(1)}')
" 2>/dev/null | tail -50
```

## Calculating system uptime

```bash
# One-shot uptime calculation — replace YEAR, MONTH, DAY, HOUR, MIN, SEC with actual integers
# MUST use << EOF (no quotes) so $EVTX expands. ET.fromstring avoids all quoting issues.
EVTX=$(find '{evidence}' -iname 'System.evtx' 2>/dev/null | head -1)
python3 << EOF
from Evtx.Evtx import Evtx
from datetime import datetime, timezone
import xml.etree.ElementTree as ET
evtx_path = '$EVTX'
target_dt = datetime(YEAR, MONTH, DAY, HOUR, MIN, SEC, tzinfo=timezone.utc)
boots = []; ns = {'e': 'http://schemas.microsoft.com/win/2004/08/events/event'}
with Evtx(evtx_path) as log:
    for r in log.records():
        try:
            root = ET.fromstring(r.xml())
            eid = root.find('.//e:EventID', ns)
            if eid is not None and eid.text == '12':
                ts = root.find('.//e:TimeCreated', ns)
                if ts is not None:
                    boots.append(datetime.fromisoformat(ts.get('SystemTime','')))
        except: pass
boots_before = [t for t in boots if t < target_dt]
if boots_before:
    last_boot = max(boots_before)
    print('Uptime (s):', int((target_dt - last_boot).total_seconds()))
    print('Last boot:', last_boot)
else:
    print('No boot before target. All boots:', [str(t) for t in sorted(boots)])
EOF
# → Uptime (s): <seconds>
```

## Tips
- **Event ID 12** (Kernel-General) = actual OS start — sub-second precision — use for uptime
- **Event ID 6005** = EventLog service started (~15 s after boot) — do NOT use for uptime
- `evtxdump.py` is NOT installed (python-evtx v0.8.1 doesn't include it) — use `import Evtx.Evtx`
- NEVER use `import evtx` (omerbenamram package) — it fails with 'Failed to parse chunk header' on this evidence
- NEVER use `with evtx.PyEvtxParser(path) as p` — PyEvtxParser does not support context managers
- NEVER print all events to stdout — the output gets truncated; always extract and print only the final value
- Event logs are at `Windows/System32/winevt/Logs/` — always `find` first since the path varies
- Use `int(total_seconds())` (not `//`) for uptime in seconds — truncates fractions correctly
- For application last-run times, check `Application.evtx`
