KEYWORDS: installed, installed programs, software installed, what programs, what software, programs used, what was installed, encryption programs, encryption software, cipher, veracrypt, bitlocker, truecrypt, bctextencoder, file vault, program list, tools installed, applications, what tools, installed tools, encryption tool

## CRITICAL: run each step as a SEPARATE tool call — never combine into one command

Each step produces up to 100 lines of output. Combining steps into one command shares that budget
and will truncate results, causing you to miss programs. Run one command per tool call.

**DO NOT use file searches alone** — they miss installer-registered tools (TrueCrypt, VeraCrypt).
**ALWAYS start with Steps 1 and 2** (registry). File searches (Steps 3-4) are supplemental only.

## Step 1 — Registry uninstall keys (START HERE — most reliable)

TrueCrypt and VeraCrypt register in the Uninstall key. BCTextEncoder does NOT (it is portable).
ALWAYS exclude RegBack — `find` returns `RegBack/SOFTWARE` first if you don't.

```bash
SOFTWARE=$(find '/forensics' -iname 'SOFTWARE' -not -path '*/Users/*' -not -path '*/diagnostics/*' -not -path '*/RegBack/*' 2>/dev/null | head -1)
echo "Using: $SOFTWARE"
reglookup -p '/Microsoft/Windows/CurrentVersion/Uninstall' "$SOFTWARE" 2>/dev/null | grep -i -E 'veracrypt|bitlocker|truecrypt|bctextencoder|file.?vault' | head -20
reglookup -p '/WOW6432Node/Microsoft/Windows/CurrentVersion/Uninstall' "$SOFTWARE" 2>/dev/null | grep -i -E 'veracrypt|bitlocker|truecrypt|bctextencoder|file.?vault' | head -20
```

## Step 2 — Full NTUSER.DAT scan (portable tools — catches BCTextEncoder in Shell Bags, MUI Cache, UserAssist, etc.)

Portable tools like BCTextEncoder leave no installer footprint but appear somewhere in the user's
registry (Shell Bags, MUI Cache, UserAssist, Run keys). Dump all NTUSER.DAT keys and grep — this
covers every possible location regardless of Windows version.

```bash
find '/forensics' -iname 'NTUSER.DAT' 2>/dev/null | while read hive; do
  result=$(reglookup "$hive" 2>/dev/null | grep -i -E 'veracrypt|bitlocker|truecrypt|bctextencoder|file.?vault')
  [ -n "$result" ] && echo "=== $hive ===" && echo "$result" | head -20
done
```

## Step 3 — Prefetch files (confirms a program was executed)

```bash
find '/forensics' -ipath '*/Prefetch/*.pf' 2>/dev/null | grep -i -E 'veracrypt|bitlocker|truecrypt|bctextencoder'
```

## Step 4 — File system fallback (portable tools, leftover files)

```bash
find '/forensics' \( -iname '*veracrypt*' -o -iname '*truecrypt*' -o -iname '*bctextencoder*' \) 2>/dev/null | head -20
```

## Tips

- BitLocker is a Windows built-in feature — it will NOT appear in Uninstall keys. Detect it via policy keys or BitLocker-encrypted volume markers.
- BCTextEncoder is a portable tool — it will NOT appear in Uninstall keys. It WILL appear in MUI Cache (Step 2) and possibly Prefetch (Step 3).
- VeraCrypt and TrueCrypt appear in Uninstall keys when installed via the standard installer.
- Always run BOTH the 64-bit (`/Uninstall`) and 32-bit (`/WOW6432Node/.../Uninstall`) registry paths in Step 1.
- Run ALL four steps before concluding — a program missed in Step 1 may appear in Steps 2–4.

## CRITICAL: TrueCrypt ≠ VeraCrypt

TrueCrypt and VeraCrypt are DIFFERENT programs. Do NOT confuse them:
- TrueCrypt: legacy disk encryption, discontinued in 2014. Registry display name: "TrueCrypt"
- VeraCrypt: successor to TrueCrypt, still maintained. Registry display name: "VeraCrypt"

If the registry grep output shows "TrueCrypt" → report **TrueCrypt**, NOT VeraCrypt.
If the registry grep output shows "VeraCrypt" → report **VeraCrypt**, NOT TrueCrypt.
ALWAYS report what you actually find in the evidence — never assume one is the other.
